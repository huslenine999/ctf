# PyJail AST Sandbox (`misc/pyjail`)

## Challenge Description
Can you escape our ultralight AST-hardened Python sandbox? 
We have stripped builtins, blocked import statements, and blacklisted dangerous words like `open`, `import`, `os`, and `flag`.

## Service Information
- **Host**: `0.0.0.0` (or target IP)
- **Port**: `31339`
- **Protocol**: Raw TCP / Text line input
