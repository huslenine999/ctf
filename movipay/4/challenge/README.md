# MoviPay 4 - Roaming Bypass

A roaming settlement hub speaks a proprietary binary TLV protocol over TCP.

Provided files:

- `roam_client`: Linux x86_64 reference client, generated by `../admin/build-public-binary.sh`
- `roam_client.c`: private reference client source for local builds
- `sha256.h`: private local HMAC-SHA256 implementation used by the client
- `capture.txt`: one normal authenticated settlement session
- `server.py`: challenge service

Run locally:

```sh
./build.sh
python3 server.py
```

The service listens on TCP port `31336` by default. Set `PORT` to override it.
Set `HOST=0.0.0.0` for container or remote deployment.
